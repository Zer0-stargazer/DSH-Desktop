DSH Desktop

个人开发者 Zer0 · 非官方。里面是官方 dsh web。

初心

官方 DeepSeek Harness 在 Windows 上主要是命令行和浏览器里的 dsh web。要用它，得自己准备 Node、自己开终端、自己记端口；网页端攒下的会话、标题、外接模型，也散落在 ~/.dsh 里。这些步骤不难，但每次重复，和「打开一个窗口就能接着用」之间还隔着一层。

DSH Desktop 只补这一层：用官方 npm 包 @deepseek-ai/dsh 在独立窗口里打开 dsh web，启动和设置里可以跟着官方更新内核，也可以把本机网页端的会话、标题、外接模型和缺的密钥合并进来。默认数据和命令行那份分开，免得两个入口互相踩。

Agent 怎么跑、插件怎么装、模型怎么选，仍是官方的事。这个窗口不另做一套对话能力，也不包装成官方客户端。

声明

  • 这是个人开发者 Zer0 做的第三方窗口，不是 DeepSeek 官方产品，与 DeepSeek 公司无隶属、无授权、无合作关系。
  • 窗口里跑的就是官方包 @deepseek-ai/dsh。内核的行为、缺陷、兼容性以官方为准。
  • 这个窗口负责：启动、数据目录、会话/模型同步、内核更新、诊断导出。不负责：Agent 效果、插件、官方模型本身。
  • API Key 只存在本机，用 Windows DPAPI 加密。这个窗口不会把 Key 上传到我这边。
  • 默认数据在 %APPDATA%\DSH Desktop\dsh-home，和 ~/.dsh 分开。若在设置里选择共用，两边读写同一目录，不要同时开官方 dsh web 和这个窗口。
  • 内核是 RC，会变。主版本变化会先问你。更新失败不会覆盖你的会话。从 npm 同步官方内核往往要数分钟到十余分钟；进度到 90% 附近通常还在下载，条子偶尔会停一下，一般不是崩溃。首次打开和刚更新后的第一次启动都会偏慢。
  • 程序未签名。Windows 可能提示未知发布者。
  • 点右上角关闭会进托盘，进程和 dsh web 还在。要退出：托盘图标右键「退出」。
  • 窗口或同步的问题：优先到 本仓库 Issues 开一条；也可设置 → 诊断 → 导出报告，发 gl20070126@gmail.com。不要发送 API Key。内核、Agent、插件去 官方 Discussions。
